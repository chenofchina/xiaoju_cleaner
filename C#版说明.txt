小橘清理大师 v3.0 (C# 版)
========================================

两个版本，选一个用就行喵：

1) dist-fd\XiaoJuCleaner.exe   （176 KB）
   需要电脑装过 .NET 8 运行时（装了 .NET 8 SDK / 桌面运行时即可）。
   体积最小，启动最快。

2) dist-sc\XiaoJuCleaner.exe   （10.5 MB）
   完全免安装，任何 Win10/11 x64 直接双击就能跑。
   已开启裁剪 + 压缩，体积从 60MB 压到 10MB。

用法
----------------------------------------
双击运行 = 交互菜单
命令行参数：
  --version   看版本
  --list      列出所有清理项目
  --dryrun    只显示一键清理会做什么，不真删
  --clean     直接一键智能清理
  --scan      扫描 C 盘各目录占用排行

带 * 的项目需要管理员权限，右键"以管理员身份运行"即可。

为什么比 Python 版好
----------------------------------------
* 原生 exe，由 .NET 编译器直接产出，没有 PyInstaller 自解压外壳
  （那个外壳正是被杀软误判成 "Agent" 的原因）
* 扫描速度：C 盘全盘 22 秒（Python 版 49 秒），多线程并行扫描
* 菜单中文列宽按 2 格计算，对齐不再错位
